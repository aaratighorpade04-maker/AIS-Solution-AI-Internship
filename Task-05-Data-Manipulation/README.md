## Task 5 – Data Manipulation with Pandas

### Objective

The objective of this task is to understand Pandas and perform different data manipulation and analysis operations using Series and DataFrames.

### Topics Covered

* Introduction to Pandas
* Series and DataFrames
* Creating data manually
* Indexing and slicing
* Data cleaning using `isnull()`, `dropna()`, and `fillna()`
* Renaming columns using `rename()`
* Filtering data
* Grouping and aggregation using `groupby()`, `sum()`, `mean()`, and `count()`
* Merging using `pd.merge()`
* Concatenation using `pd.concat()`
* CSV and Excel file handling
* Time series using `pd.to_datetime()` and `resample()`
* Basic visualization using `df.plot()`
* Condition selection using AND (`&`) and OR (`|`)

### Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Jupyter Notebook
* GitHub
