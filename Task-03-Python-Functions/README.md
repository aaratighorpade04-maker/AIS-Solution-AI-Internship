## Task 3 – Python Functions

### Objective

The objective of this task is to practice defining and using Python functions for different operations on lists and strings.

### Tasks Completed

1. **Find Maximum**

   * Created a function to find the maximum value from a given list.

2. **Sum of Numbers in a List**

   * Created a function to calculate the sum of all numbers in a list.
   * Example: `[8, 2, 3, 0, 7]` → `20`

3. **Distinct Elements**

   * Created a function that returns a new list containing only distinct elements.
   * Example: `[1, 2, 3, 3, 4, 5]` → `[1, 2, 3, 4, 5]`

4. **Combinations**

   * Created a function to calculate combinations.
   * Example: `a, b, c` selecting 2 → `ab, ac, bc`
   * Total combinations = **3**

5. **Permutations**

   * Created a function to calculate permutations.
   * Example: `a, b, c` selecting 2 → `ab, ac, ba, bc, ca, cb`
   * Total permutations = **6**

6. **Count Vowels and Consonants**

   * Created a function to count vowels and consonants in a word.
   * Example: `statistics`
   * Vowels = **3**
   * Consonants = **7**

7. **Convert Lowercase to Uppercase**

   * Created a function to convert lowercase words into uppercase.
   * Example: `statistics` → `STATISTICS`

8. **Count Uppercase and Lowercase Letters**

   * Created a function to count uppercase and lowercase letters.
   * Example: `STatiStiCS`
   * Uppercase = **5**
   * Lowercase = **5**
