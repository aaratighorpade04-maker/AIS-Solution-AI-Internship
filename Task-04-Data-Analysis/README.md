## Task 4 – Data Analysis with NumPy

### Objective

The objective of this task is to understand NumPy and its applications in numerical computation and data analysis using Python.

### Topics Covered

#### 1. Introduction to NumPy

* Introduction to NumPy and its importance.
* NumPy installation using `pip install numpy`.
* Role of NumPy in Data Science, Machine Learning, and Scientific Computing.

#### 2. Arrays in NumPy

* Understanding the `ndarray` (N-dimensional array).
* Creating arrays using:

  * `np.array()`
  * `np.zeros()`
  * `np.ones()`
  * `np.arange()`
  * `np.linspace()`
* Array indexing and slicing.

#### 3. Array Operations

* Addition, subtraction, multiplication, and division.
* Element-wise operations.
* NumPy mathematical functions:

  * `np.sqrt()`
  * `np.sin()`
  * `np.exp()`
* Introduction to broadcasting.

#### 4. Array Shapes and Reshaping

* Understanding `.shape` and `.ndim`.
* Reshaping using `.reshape()`.
* Converting arrays using `.flatten()`.
* Transposing arrays using `.transpose()`.
* Combining arrays using:

  * `np.concatenate()`
  * `np.vstack()`
  * `np.hstack()`
* Splitting arrays using `np.split()`.

#### 5. Array Manipulation

* Multi-dimensional indexing and slicing.
* Boolean masking.
* Selecting elements using fancy indexing.

#### 6. Mathematical Functions

* Universal functions (ufuncs):

  * `np.add()`
  * `np.subtract()`
  * `np.multiply()`
* Statistical functions:

  * `np.mean()`
  * `np.median()`
  * `np.std()`
  * `np.var()`
  * `np.min()`
  * `np.max()`
* Linear algebra functions:

  * `np.dot()`
  * `np.matmul()`
  * `np.linalg.inv()`
  * `np.linalg.eig()`

#### 7. Random Number Generation

* Generating random numbers using `np.random.rand()`.
* Generating random integers using `np.random.randint()`.
* Setting a seed using `np.random.seed()`.
* Random sampling.
* Shuffling arrays.
* Generating random permutations.

#### 8. Broadcasting

* Understanding broadcasting in NumPy.
* Performing operations between arrays of different shapes.
* Understanding NumPy broadcasting rules.
* Applying broadcasting to matrices and arrays.
